# Veux-tu être ma Valentine ? 💖

Une déclaration de Saint-Valentin interactive : la page pose la question « Veux-tu être ma Valentine ? ».
Le bouton **Non** s'enfuit dès qu'on essaie de cliquer dessus, et le bouton **Oui** déclenche une explosion de cœurs.

👉 **Voir le site : https://assogbamarcos645-pixel.github.io/My-valentine-/**

## Fonctionnalités

- Bouton « Non » qui s'enfuit (souris, tactile et clavier)
- Bouton « Oui » qui grossit à chaque refus
- Animation de cœurs et message de célébration
- Adapté aux mobiles et accessible

## Technologies

HTML, CSS et JavaScript, sans dépendance. Le site est hébergé sur GitHub Pages.
